Performance analysis

Formulas
  • Schedule gap (pp) = Actual weighted completion % − Planned weighted completion %. A progress difference, not days or weeks.
  • Simple spending variance = Planned spending to date − Actual spending to date. Negative means spending is above the planned-to-date amount.
  • Due WBS acceptance % = Accepted deliverables ÷ Deliverables due × 100.
  • Test pass rate % = Passed tests ÷ Tests run × 100.
  • EVM (optional): SV = EV − PV · CV = EV − AC · SPI = EV ÷ PV · CPI = EV ÷ AC.

Simple spending variance vs EVM CV. Simple spending variance compares planned spend with actual spend; it ignores how much work was actually accepted. EVM cost variance (CV = EV − AC) compares the budgeted value of accepted work with what was spent, so it can be far more negative. They answer different questions and must not be labelled interchangeably.
